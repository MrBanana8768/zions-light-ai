# V4 Local Lab

See [LAB.md](LAB.md) for everything: one-command up/down, how to log in,
how to (re)import her history, how to reset, and where the logs are.

Quick start:

```bash
bash lab/v4/scripts/v4lab-up.sh
bash lab/v4/scripts/v4lab-copy-data.sh
bash lab/v4/scripts/v4lab-import.sh
```

Then open http://localhost:18009 and log in as `her` (password in
`lab/v4/.env.lab`, not in git).
